# Rinspace Web Support

## Community support

Use GitHub issues for reproducible bugs and focused feature requests in the public Web frontend. Before filing, search existing issues and include the affected version or commit, browser and operating system, runtime mode, minimal reproduction, expected result, and actual result. Use synthetic or redacted data only.

Community support is provided on a best-effort basis. No response time, fix time, compatibility promise, or service level is created by an issue, discussion, pull request, or release note.

## Out of scope

The public repository does not provide operational support for the private Rinspace backend, production accounts, customer data, private infrastructure, or third-party deployments. Do not post credentials, personal information, private logs, or vulnerability details in a public issue.

## Security and commercial support

- Security vulnerabilities: follow [`SECURITY.md`](./SECURITY.md).
- Commercial licensing or separately contracted support: `lunifans@outlook.com`.

Paid support, warranties, hosting, or custom integration exist only when stated in a separate written contract signed by authorized parties. Purchasing support is not required to use the AGPL-licensed software in compliance with its terms.
