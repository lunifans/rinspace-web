# Rinspace 用户服务协议

版本：`2026-09-05-effective.1`；生效日期：2026-09-05。

欢迎使用 Rinspace。Rinspace 由任务优先（上海）网络科技有限责任公司（下称“我们”）运营。本协议适用于 Rinspace 网站的表世界知识内容和里世界社区服务。联系邮箱：`lunifans@outlook.com`。

## 一、协议订立与变更

在注册、登录或使用需登录的功能前，请阅读本协议、隐私政策、社区规则、算法推荐说明及界面内的专项规则。对影响用户权益的重大变更，我们会以显著方式告知；依法需要重新取得同意的，在取得同意前不按新目的处理信息或开放相应功能。

## 二、账号和真实身份

1. 账号使用 Rinspace 统一身份。表世界与里世界的 `@username` 是同一主体的两个视图，头像、共享资料和粉丝关系不形成两套身份。
2. 发布、回复、点赞、转发、收藏、私信等社区能力仅向已完成平台要求的真实身份认证且账号状态正常的用户提供。前台名称可由用户在规则允许范围内选择。
3. 用户应提供真实、准确、合法的信息，不得冒用他人或组织身份，不得买卖、出租、出借账号。认证材料与公开资料分区保存和授权，不公开展示认证信息。
4. 当前里世界写入能力仅面向经核验年满 18 周岁的用户。无法完成年龄或身份核验时，可以使用依法允许的公开只读功能，但不能发布或互动。
5. 用户应妥善保护账号和登录凭据，发现异常应立即联系我们。平台不会要求用户向第三方披露验证码或私钥。

## 三、用户内容与许可

1. 用户对其发布、上传、编辑或转发的文字、图片、音视频、链接及其他内容负责，并应具有相应权利或合法授权。
2. 用户保留其依法享有的知识产权。为提供存储、展示、检索、分享、备份、审核、安全和版本管理功能，用户授予我们在服务存续期间、服务所必需范围内处理相关内容的非独占许可。该许可不允许我们脱离服务目的出售用户作品。
3. 删除内容后，我们会按产品规则停止公开展示；依法需要保存的安全日志、处置记录、备份或争议证据可在必要期限内隔离保存，到期删除或匿名化。
4. 帖子的稳定网页地址为 `/p/:id/:slug`，其中 ID 用于定位，slug 仅用于可读性。个人主页 handle 可变，不作为内容归属或粉丝关系的长期主键。

## 四、禁止行为

用户不得利用服务制作、复制、发布或传播法律法规禁止的信息，不得实施侵害国家安全和公共利益、他人生命健康、名誉、隐私、个人信息、知识产权或其他合法权益的行为。以下行为也被禁止：

- 侮辱谩骂、造谣诽谤、威逼胁迫、煽动仇恨、歧视、曝光他人隐私或组织网络暴力；
- 发布或传播时政、社会政治、政治人物或机构、政治事件、群体号召、组织动员或煽动性内容；
- 冒充新闻机构、政府机关、企业或他人，伪造权威来源；
- 发布违法营销、诈骗、赌博、色情、毒品、危险品交易或恶意引流信息；
- 未经同意批量抓取个人信息、骚扰他人、规避屏蔽或重复注册逃避处置；
- 利用程序、虚假账号或交易操纵点赞、转发、评论、浏览量、热度和推荐；
- 攻击、探测、干扰服务，绕过访问控制，传播恶意代码或利用漏洞牟利。

社区规则会进一步说明违法和不良信息、网络暴力、垃圾信息及内容警告的处理标准。

## 五、内容治理与账号处置

1. 我们可以依法依约采用机器识别和人工复核进行发布审核、实时巡查、举报处理和风险处置。机器审核不可用或结果不确定时，高风险写入可延迟发布或拒绝发布。
2. 根据内容、行为、影响和重复程度，我们可采取提示、拒绝发布、降低传播、添加警示、限制互动、删除、限制账号功能、暂停更新、关闭账号、禁止重新注册、保存证据或依法报告等措施。
3. 紧急情况下，为防止人身、财产、隐私或系统安全损害扩大，我们可以先采取必要措施，再按规则通知和复核。
4. 用户可以通过站内入口或 `lunifans@outlook.com` 举报、投诉或申诉。我们会核验并反馈；需要补充材料时会说明。涉未成年人、网络暴力、人身安全和个人信息泄露事项优先处理。

## 六、推荐、浏览量与第三方服务

1. 里世界可提供个性化“推荐”和按时间排列的“正在关注”。推荐会显著标识，用户可以关闭个性化、选择非个性化结果、查看或删除兴趣标签并清除推荐画像。详情见算法推荐说明。
2. “浏览次数”是经短期技术去重后的累计展示次数，不表示独立访客。我们不建立永久逐次浏览轨迹表；关闭个性化后不再把合格阅读信号用于推荐画像。
3. 链接指向的第三方服务由第三方独立运营。我们不会以本协议替第三方作出承诺，但会依法处理平台内的违法链接和侵权投诉。

## 七、服务变更、中断与终止

我们会维护服务安全和连续性，但维护、故障、网络、不可抗力或依法处置可能导致中断。对可预见的重要维护会尽可能提前通知。账号注销后，我们按隐私政策处理个人信息；法律法规要求保存或争议处理所必要的信息除外。

我们依法承担平台责任。本协议不排除或限制法律规定不得排除或限制的责任。用户与我们发生争议时，可先通过联系邮箱协商；协商不成的，任何一方可依法向有管辖权的人民法院提起诉讼。
