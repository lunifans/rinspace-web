> 文书版本：`2026-09-05-draft.1`

本目录保存 Rinspace 表里世界面向中国大陆用户的公开文书候选稿。运营主体为**任务优先（上海）网络科技有限责任公司**，联系邮箱为 `lunifans@outlook.com`。

| 文书 | 用途 |
| --- | --- |
| [用户服务协议](./用户服务协议.md) | 账号、内容许可、服务规则、处置与申诉 |
| [隐私政策](./隐私政策.md) | 个人信息清单、目的、期限、权利与安全事件 |

这些文书采用分层披露：界面在收集信息、开启推荐和执行处置时仍须就具体目的、范围、影响及用户权利作即时提示。文书不能代替真实身份认证、内容治理、权限检查、审计、备案或安全评估等工程和运营控制。

正式上线前必须：

1. 用实际产品、数据流和保留期限逐段复核，不得保留不真实或尚未实现的承诺；
2. 填写生效日期、ICP备案、公安备案以及适用的算法备案/安全评估材料；
3. 在注册、发帖、推荐设置和举报入口展示相应文书，并保存版本化同意或告知证据；
4. 对重大变更重新告知，依法需要同意时重新取得同意；
5. 由公司指定负责人签署发布记录。没有签署记录时，里世界写入和个性化推荐保持关闭。
